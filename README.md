# 截改 AI · SnipRefine

[简体中文](README.md) | [English](README.en.md) | [Español](README.es.md)

以 AI 局部图片修改为核心的 Windows 工具：打开图片或截图，框选目标，去字修补、替换文字或局部重绘，预览确认后保存。兼具手工标注、OCR、翻译和看图对话。

**版本：1.22.1 体验试用版 · C# / Windows Forms · [MIT License](LICENSE)**

## 操作流程

完整操作步骤见 [使用说明](docs/USER-GUIDE.md)，运行软件后可按 F1 打开离线帮助。

典型流程：打开图片或截图 → AI 框选 → 保护重要内容 → 选择修改任务 → 预览确认 → 保存。

## 核心功能

- **图片编辑任务**：独立图片编辑服务配置（支持 OpenAI Images Edits 与 Gemini 原生实验协议）；去字修补、局部重绘，以及 AI 修补背景后由本机排版的新文字替换。需所配置服务支持图片编辑，生成效果待真实 API 实测。
- **蒙版与确认**：保护/恢复画笔、上传范围确认、生成结果确认；选区外与保护区由本地合成保留原像素。

- **三种截图方式**：快速框选、可移动和缩放的框选、全部显示器桌面截图，支持自定义全局快捷键。
- **手工编辑**：画笔、直线、箭头、矩形、椭圆、文字、马赛克、实心遮挡、视觉模糊、裁剪与连续序号；支持撤销和重做。
- **AI 局部框选**：独立选区、局部 PNG 上传、目标编号预览与确认；客户端限制绘制范围，选区外保持不变，支持撤销。
- **AI 辅助修改**：用自然语言描述标注、遮挡或裁剪要求，预览并确认修改结果。
- **OCR 与翻译**：通过支持图片输入的模型识别文字、返回译文，识别结果可复制。
- **看图对话**：选择本地图片或最近截图作为附件；支持多提供商配置、模型选择、连接及看图测试。
- **输出与恢复**：独立保存和另存为保持编辑器打开；保存后打开图片或位置；后台保存与复制失败可恢复最近一张完整图片。
- **文字结果与历史**：OCR/翻译结果可独立查看、编辑和复制；可选跨重启记录已保存图片的本机路径，默认关闭。
- **本地输出与界面**：复制或保存为 PNG/JPEG，配置截图目录；提供明亮/深色主题和最近截图预览。

## 界面与工作流程

启动后直接打开原主窗口，设置在主窗口中展示。编辑器左侧为标注工具，中间为画布，右侧为 AI 修改与识别；顶部集中保存、复制、撤销和缩放操作。小窗口下工具与 AI 命令分别滚动。右侧 AI 操作按选区、图片修改和文字识别分组。新增橡皮擦，局部擦除手工标注并保留底图，支持撤销；效果画笔明确标为马赛克/遮挡/模糊画笔。每个设置页底部只有一个独立保存按钮；语言独立成页，提供简体中文、English、Español，保存后重启生效。详见 [使用说明](docs/USER-GUIDE.md)。

## 下载与快速开始

源码仓库仅包含源码、图标、文档和构建工具。程序发行包 `SnipRefine-1.22.1-win.zip` 通过 Releases 单独分发，`dist/` 由本地构建生成。

在仓库的 **Releases** 页面查找 `SnipRefine-1.22.1-win.zip`。若没有可用的发行附件，请按下文从源码构建。

1. 解压程序发行 ZIP，进入包含 `SnipRefine.exe` 的目录。
2. 双击 `SnipRefine.exe` 启动。完整源码包可双击根目录 `Start.cmd`，使用 Windows .NET Framework 编译器重新编译并启动；错误会留在命令窗口。
3. 在主窗口使用截图入口，或按 `Ctrl+Alt+A` 框选并确认。修改后点击「保存」继续编辑，或选择「复制并保存」结束本次编辑。

截图和手工编辑不需要 AI 密钥。首次使用 AI，请先完成下文的提供商配置。

## 使用说明

### 常用快捷键

| 默认快捷键 | 操作 |
|---|---|
| `Ctrl+Alt+A` | 可调整框选，确认后进入编辑器（默认启用编辑器时） |
| `Ctrl+Alt+S` | 快速框选，松开后直接保存并按设置复制 |
| `PrintScreen` | 截取全部显示器桌面，默认进入编辑器，可切换直接保存 |
| `Ctrl+S` / `Ctrl+Shift+S` | 只保存 / 另存为，保存后继续编辑 |
| `Ctrl+C` | 仅复制；编辑文字时优先复制文字 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Esc` | 按当前操作取消框选、文字输入或 AI 请求等 |
| `F1` | 打开离线使用说明 |

三组截图快捷键可在设置中修改；被其他软件占用时可改键或使用按钮、托盘菜单。

### 配置 AI

打开 **设置 → AI 助手**，使用「快速配置向导」，选择服务、填写 API Key 和模型、执行文本和看图测试，再保存配置。高级选项可修改接口地址和协议；原提供商设置仍可编辑。文本连接成功不代表模型支持图片输入。

需要局部修改时，点击编辑器的「AI 框选」并拖出区域，再输入要求。局部模式只发送选区图片与本次要求，不发送整图和旧会话；返回后核对目标编号和识别文字再确认。详细说明见 [AI 局部编辑](docs/AI-REGION.md)。

编辑器 AI 面板可输入「遮挡左上角手机号」「用箭头标出错误提示」「裁剪掉底部空白」等具体要求。主界面对话用于问答；实施图片修改需进入编辑器。

图片编辑服务与三个任务的配置和隐私范围见 [图片编辑说明](docs/IMAGE-EDITING.md)。发送前会确认选区及周围最多 32 像素的上传范围；确认后才调用，可能计费，不自动重试。

完整快捷键、保存设置、附件与故障排查见 [使用说明](docs/USER-GUIDE.md)；版本变化见 [发行说明](docs/RELEASE-NOTES.md)。

## AI 能力与隐私说明

- **能力范围**：模型返回标注、文字、马赛克、实心遮挡、模糊、裁剪及 OCR 指令，由本地客户端执行。这是普通 AI 发送入口的范围；独立「局部重绘」入口可请求图片编辑服务修改选区内容，实际效果取决于服务及模型。暂不提供自动对象轮廓分割。
- **结果确认**：新配置默认启用应用前确认；支持修改前后对比和撤销。AI 不会自动保存或复制，最终输出由用户选择。
- **图片发送**：截图和手工编辑在本地进行。编辑器整图 AI 请求发送当前编辑结果及要求；局部指令模式仅发送选区图片与本次要求；图片重绘模式发送预览确认的局部上下文、蒙版和要求；对话发送所选附件，自动附带最新截图默认关闭。相关内容会传到配置的服务接口；使用远程服务时会离开本机。
- **密钥与配置**：API Key 使用 Windows DPAPI，按当前 Windows 用户加密保存。配置位于 `%APPDATA%\SnapGrab\SnapGrab.ini`，不要将配置、密钥或私人截图提交到仓库。
- **隐私遮挡**：敏感内容建议先用不透明实心遮挡，再检查最终图片。视觉模糊和马赛克不保证原内容无法辨认。
- **使用成本**：模型服务可能收取调用费用；取消客户端请求不保证服务端停止计费。OCR、译文和标注结果应在输出前核对。

手动启动显示主窗口；重复启动会尝试唤醒现有窗口。启动异常会弹出提示，并在配置目录生成 `startup-error.log`，不记录异常正文或文件路径。

## 从源码构建

在 Windows 上取得完整源码，进入项目根目录，在命令提示符中执行：

```bat
scripts\build.cmd
```

输出：`dist/SnipRefine.exe`。脚本使用 C# 5、AnyCPU 和 .NET Framework 引用编译；先编译临时程序，成功后替换 EXE；不会强制结束正在运行的软件。替换失败时请从托盘退出后重试。

生成程序发行 ZIP：

```bat
scripts\pack.cmd
```

输出：`dist/SnipRefine-1.22.1-win.zip`。程序发行包用于运行软件，不包含完整源码和构建脚本。
