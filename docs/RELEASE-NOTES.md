# SnipRefine 1.22.1

本页说明本次发行的内容与验证范围。完整版本历史见 [CHANGELOG](../CHANGELOG.md)。

## 1.22.1

- 语言独立为侧边栏设置页，分别保存、提示未保存和收起；主题保存不会带入语言草稿。
- README 提供中文、英文和西班牙文顶部切换链接。
- 79 组 Linux/Mono/Xvfb 回归覆盖独立语言保存。
- Windows 10 22H2 实机复核：79 组回归通过、0 失败；启动无错误日志；Ctrl+Alt+A / Ctrl+Alt+S / PrintScreen 三组全局快捷键注册成功；资源压力 4 轮内存与句柄无增长。

## 1.22.0 多语言与图片服务适配

- 外观页新增简体中文、English、Español；保存本页后重启应用，语言配置独立持久化。
- 扩充核心工具、AI 编辑、上传范围、预览确认与服务设置的英/西语言资源；未覆盖的西语文案回退英文，再回退原文，不宣称完整翻译。用户输入和服务回复保留原文。
- 图片编辑新增 Gemini 原生 `generateContent` 实验协议；保留 OpenAI Images Edits 与兼容接口。Gemini 使用权限参考图指导生成，本地仍严格按蒙版回写，选区外与保护区保留原始像素。
- Gemini 不下载外部 URL，拒绝无图片、多个图片、不匹配比例或超限响应；返回方形图规范化为 1024 像素后预览。
- 根据发布选择继续提供未签名 EXE。
