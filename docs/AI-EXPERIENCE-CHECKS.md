## 一次完整流程

1. 解压运行包并启动；配置图片编辑服务。文本或看图连接通过不能代替图片编辑模型支持。
2. 打开样图、AI 框选。核对工具状态，必要时设置保护区。
3. 输入新文字，先用过大的字号确认错误留在输入窗口，再调小字号。排版预览默认放大选区，切换完整图片核对位置。
4. 点击继续，核对发送预览；先取消一次，应明确提示未发送。重新操作后确认发送，真实请求可能计费。
5. 结果预览切换修改前、修改后及完整图片。先保留原图，应没有应用；再次生成会产生新的请求及可能的费用，不自动重试。
6. 应用结果、撤销、重做，确认图片和标注恢复；保存、另存为和复制分别检查输出。
7. 修改两个设置页，只保存其中一个，另一页应保留未保存标记。恢复原值应清除标记。
8. 存在设置草稿时关闭或退出，选择否应留在当前窗口；选择是放弃草稿。重新启动检查只有明确保存的内容被保留。

记录每次验收的系统、屏幕缩放、服务/模型 ID、指令和结果；记录中不包含 API Key。需要归档图片时由用户明确选择，不自动保存私有测试图片。

## Windows 显示验收

依次检查 100%、125%、150%、200% 缩放，单屏及多屏不同缩放、屏幕负坐标、窗口最大化与恢复、侧栏开关。对框选、箭头拖动、保护画笔、结果预览与底部按钮分别核对。尚未在 Windows 实机执行这些步骤；本版本已执行 Linux/Mono 自动回归，二者分开记录。
