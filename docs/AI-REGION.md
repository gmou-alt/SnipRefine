# AI 局部框选编辑

## 使用步骤

1. 截图进入编辑器，点击「AI 框选」。
2. 在图片上拖出至少 2 × 2 像素的区域，青色虚线显示发送范围。重新拖动可调整；缩放与平移不会改变已保存的原图选区坐标。
3. 输入「识别框内文字」「用实心遮挡隐藏框内手机号」「用箭头指出框内错误」等要求并发送。
4. 返回后在确认窗口查看局部图及橙色目标编号，核对下方操作、识别文字和坐标；勾选后应用。识别错误可以放弃、重选、重发；OCR/译文也可在结果窗口编辑后复制。
5. 用修改前/后比较结果，或撤销本次；检查后自行保存或复制。

「清除AI选区」或在画布按 Esc 清除选区并退出框选模式。之后发送整张当前图片。若已有请求，先取消请求再修改发送模式。等待时更改图片或选区，旧回复不会应用。

## 实现范围

- 只上传框内当前编辑结果的 PNG 与本次要求，省略旧会话；不自动发送邻近区域或整图。选区长边仍遵守 AI 图片上传尺寸设置，较小选区保持原分辨率。
- 使用原图像素坐标保存选区，分别按实际上传宽高映射模型坐标，包含缩放尺寸四舍五入的处理。
- 支持现有标注、文字、实心遮挡、马赛克、模糊及 OCR 指令。非有限坐标、未知操作或越界操作整批拒绝，不部分执行。
- 局部有操作时始终确认，包括 OCR。预览显示模型返回的目标位置，未接入独立对象分割模型；模型仍可能识别错误或遗漏文字边界，不能声称完全准确。
- 局部 AI 标注带固定绘制边界；文字与线条溢出会被截断，撤销重做保留边界。后续手动移动这些标注仍受原边界限制，若需跨区域编辑请撤销并重新框选。
- 局部裁剪会改变整图，当前拒绝。需要裁剪时清除 AI 选区，使用手工裁剪或整图 AI。
- 选框和目标预览不写入最终图片。

本说明描述普通 AI 发送的指令式编辑。去字修补、替换文字与局部重绘使用独立图片服务，配置、上下文上传和蒙版保护见 [图片编辑说明](IMAGE-EDITING.md)。对象轮廓自动分割尚未实现。

## 验证

自动检查覆盖局部 PNG 内容、按宽高分别映射、非法批次原子拒绝、不同缩放和平移下鼠标框选、预览尺寸、选区外逐像素一致及撤销重做。

未用真实 API 运行本版完整局部识别流程。此前已有真实 AI 连通反馈，但不代表本次局部识别或全部模型通过。Windows 人工操作和模型效果仍需实测，结果以实际记录为准。
