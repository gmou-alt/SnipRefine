# 图片编辑：去字修补、替换文字与局部重绘

## 首次配置

主界面「外观 → 图片编辑服务设置」，或编辑器「图片编辑设置」。这份配置与文本/看图提供商独立：完整编辑请求地址、图片编辑模型 ID、API Key。

当前适配 OpenAI Images Edits 格式：`multipart/form-data` 上传 PNG 图片和带 alpha 的蒙版，请求一张 `1024x1024` PNG，响应需要 `data[0].b64_json`。默认地址为 `https://api.openai.com/v1/images/edits`；自定义兼容服务需实际支持这些字段，不是任意聊天 API 都能使用。API Key 使用本机当前用户 DPAPI 加密保存，不写进公开包。

另可在同一处选择 **Gemini Native (Experimental)**：使用原生 `generateContent`，上传原图、文字要求与黑白权限参考图，本地仍严格按选区与保护蒙版回写像素；Gemini 无原生等价蒙版保证，生成内容可能不完全遵守参考图。两条协议的字段、限制与配置示例见 [AI 服务兼容性](SERVICE-COMPATIBILITY.md)。

参考：[官方图片编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)。默认模型可在设置修改；权限和收费由所选服务决定。文本连接或看图测试通过不等于图片编辑通过。

## 操作流程

1. 主界面点击「打开图片修改」，或截图进入编辑器。
2. 点击「AI 框选」，框住要处理的位置。尽量围绕目标保留少量背景。
3. 需要保护选区内 Logo、商品结构或其他文字时，使用「保护画笔」涂抹；红色表示保护。用「恢复修改」擦回允许修改区域。点击「画笔大小」循环切换 4 / 8 / 16 / 32 / 64 原图像素；「清空保护」恢复整个选区可编辑。暂不提供自动轮廓分割。
4. 选择任务：
   - **去字修补**：要求图片模型清除允许区域中的文字并修补背景。
   - **替换文字**：输入新文字；先清除原文字、修补背景，再在本机按替换窗口设置的字号及工具栏颜色排版新字。暂不自动匹配原字体和基线，发送前检查文字是否放得下，并提供不调用服务的本机排版预览；超出时先调小字号、减少文字或重新框选。保护区仍可能遮挡文字，务必核对。
   - **局部重绘**：在 AI 输入框描述要求，例如去除选区内杂物，再点击此按钮。
5. 预览发送范围并确认。绿色覆盖是允许修改区域；实际上传图片不包含提示颜色和界面标签。
6. 等待生成，检查最终结果，再确认应用或放弃。应用后可修改前/后对比、一步撤销/重做，最后自行保存。

普通 AI「发送」仍执行标注/OCR 指令，不调用图片生成；保护画笔只用于上述三个图片编辑任务。

## 范围与隐私

上传包括选区周围最多 32 原图像素的上下文；发送前完整预览。不会自动附带整图、旧会话或其他附件。输入被等比缩放并置于 1024 方形画布，蒙版与图片保持对齐。大选区可能缩小，细字效果需要实测。

蒙版透明部分允许模型编辑，但模型可能改变输入的其他部分。客户端按原图选区和保护蒙版重新合成：选区外和受保护像素来自原图，不写入模型返回的对应区域。边缘暂采用硬边界，复杂纹理可能有接缝；不自动扩大修改权限。

替换任务中的新文字在本机绘制，不放进背景修补请求。它会按替换窗口字号和工具栏颜色绘制，并受同一蒙版限制；这不是自动复刻原字形。

## 请求与恢复

请求显示真实等待时间，支持取消；没有虚构百分比。不会自动重试、自动换服务或自动下载返回 URL。失败、取消或放弃保持当前图片；选区、普通要求和替换文字输入保留在本次编辑器会话内。手动重试可能再次计费，取消不保证服务端停止生成或计费。

等待期间更改图片、选区或蒙版，旧结果不会应用。返回尺寸不是 1024 方形、响应缺少 base64 图片或格式异常时拒绝应用。

确认生成结果会将当前合成图作为新的位图底图，已有标注暂不能逐个调整；一步撤销可恢复生成前的底图和原标注。后续新标注仍可编辑。
