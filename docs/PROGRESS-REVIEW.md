# 进度与已知限制

基准版本：**1.22.1**。本文件记录当前完成范围、已执行的验证，以及尚未完成的部分。范围检查不能证明软件不存在其他缺陷。

## 当前进度

- **截图**：可调整框选、快速框选、全部显示器截图；三组全局快捷键可自定义。
- **编辑**：画笔、直线、箭头、矩形、椭圆、文字、马赛克、实心遮挡、视觉模糊、橡皮擦、裁剪与连续序号；支持撤销重做、工具属性栏与左工具 / 中画布 / 右 AI 三栏布局。
- **AI**：多提供商文本与看图配置、配置向导、故障处理建议、OCR 与翻译、AI 局部选区；独立图片编辑服务支持 OpenAI Images Edits 与 Gemini 原生（实验）协议，含保护蒙版、发送范围预览与结果确认。
- **设置**：每页独立保存、未保存标记、离开时按需提醒；语言独立成页，提供简体中文、English、Español（部分翻译），保存后重启生效。
- **隐私**：AI 与图片编辑密钥均经 Windows DPAPI 加密；图片编辑只上传选区及周围最多 32 像素；不接受服务返回 URL 的自动下载；不写诊断日志（仅启动异常生成脱敏记录）。

## 已执行的验证

- 官方 .NET Framework 4.5 参考程序集编译，C# 5、AnyCPU，警告按错误处理，通过。
- Linux / Mono / Xvfb：79 组自动回归通过，0 失败。
- **Windows 10 22H2 实机**：79 组回归通过、0 失败；干净启动且无 `startup-error.log`；Ctrl+Alt+A / Ctrl+Alt+S / PrintScreen 三组全局快捷键均注册成功；资源压力 4 轮批量内存与句柄无增长（私有约 34 MB、工作集约 63 MB、GDI 句柄 38、用户句柄 23）。
- 回归覆盖：窗口尺寸（700×560 / 1200×800 / 1920×1080）布局与按钮对齐滚动、设置页保存隔离与草稿、橡皮擦像素恢复、蒙版合成与选区外像素一致、AI 局部坐标映射与越界拒绝、两套图片编辑协议的本地模拟 HTTP（成功/失败/认证/隐私）、撤销恢复、隐私地址校验与密钥加密。
- 打包检查：版本资源、DPI manifest、文档链接、ZIP 完整性、常见密钥格式；发行包不含本机配置、私人图片、历史与日志。

## 已知限制与后续优先级

| 优先级 | 项目 | 现状 | 验收方式 |
|---|---|---|---|
| P0 | 真实图片编辑服务效果 | **未验证**：两套协议都只经本地模拟服务测试 | 用 `docs/fixtures/` 的固定样图分别跑 OpenAI Images Edits 与 Gemini，保留原图、选区、指令与结果 |
| P0 | Windows 多屏、混合 DPI 与完整人工交互 | **未验证**：实机环境为单屏 1920×1080 @100% | 按 `docs/WINDOWS-CHECKS.md` 与 `docs/ACCEPTANCE.md` 逐项记录 |
| P1 | 代码签名 | EXE 未签名，下载运行可能触发 SmartScreen 提示 | 自备证书后按 `docs/SIGNING.md` 打包 |
| P1 | 多语言完整度 | 简体中文完整；English / Español 为部分翻译，未覆盖项回退 | 补齐后用 `docs/ACCEPTANCE.md` 的语言项核对 |
| P1 | 图片编辑服务适配面 | 已适配 OpenAI Images Edits 与 Gemini 原生（实验） | 新增协议时参照 `docs/SERVICE-COMPATIBILITY.md` 记录字段与限制 |
| P2 | 设置响应式布局 | 仍有多处坐标计算 | 改用共享内容区规则，并补侧栏开关与缩放往返的布局验收 |
| P2 | 真实 AI 文本/看图矩阵 | 使用者反馈连接通过，未做全模型矩阵记录 | 按提供商与模型分别记录，不扩写为所有功能通过 |
